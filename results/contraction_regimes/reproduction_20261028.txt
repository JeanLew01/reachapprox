Contraction figure and numerical summaries
The original sample_complexity.csv is retained for the markers: 28 horizons per
set from 0 through 6.75, spaced by 0.25. sample_complexity_dense.csv archives the
solid steps: 1,351 horizons per set on the same closed interval, spaced by 0.005.
Both use 200 saved trials per set and NumPy quantile(method="higher") at 0.95.
Every one of the 56 coarse summary rows equals its corresponding dense row.

The first single-sample horizons on the 0.005 grid are:
  square: T = 4.330 (the preceding grid value T = 4.325 still needs >1 sample)
  array:  T = 6.150 (the preceding grid value T = 6.145 still needs >1 sample)
An independent check using only the N=1 raw errors gives continuous crossings
log(quantile_0.95(initial_error)/0.03) of 4.32714829123139 and 6.147019575483883,
respectively, confirming the first successful grid horizons.
The array empirical complexity is 45 at every dense horizon in [3.25, 5].
Fits to the coarse horizons T <= 2.75 give rates -2.0791834951490884 (square)
and -2.0244461452862597 (array), matching the reported -2.08 and -2.02.
The trials.csv and coarse sample_complexity.csv are byte-identical to baseline.

The preexisting local plotting revision already reproduced the original TAC
contraction PNG exactly. This revision preserves those steps and visual styling,
archives their numerical summary, and ends the dense grid at 6.75, the same
endpoint as the markers. Removing the unused final T=6.755 value leaves the PNG
byte-identical to the original manuscript figure.

One-sided Lipschitz figure
The selected figure is the repository version regenerated by the second command.
Its source, trials.csv, growth_rates.csv, and PNG are unchanged from the baseline
commit. The revised TAC manuscript uses this reproducible PNG.
