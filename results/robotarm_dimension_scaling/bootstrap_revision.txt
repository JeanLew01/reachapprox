Robot-arm seed-bootstrap correction, 2026-10-28

Base code commit: 25be4480199b0fca6cc22e5dc768eb268ae9474d.
This record documents the 2026-10-28 TAC audit revision against that baseline.

Adversarial CSV records are aligned by base_seed = seed - N. Each base seed
uses one reference subset and one random stream across all sample budgets.
The bootstrap now samples whole aligned records jointly across budgets.
Duplicate or incomplete adversarial records are rejected.

Uniform sampling also needs clustering: its saved seed formula is
EXPERIMENT_SEED + 10000*n + 100*seed_index + N, which repeats actual RNG seeds
across some budgets. For example seed 97831 occurs at N=100 and N=300 for
the 2-link arm. Each dimension has 240 observations (30 per budget), but only
179 unique RNG seeds. Of these, 142 occur once, 14 at two budgets, 22 at three
budgets and 1 at four budgets. Repeated seeds share the same reference subset
and random stream. Endpoints are not strictly nested: sample_initial_box draws
all joint positions before velocities, so the stream pairing changes with N.

The uniform bootstrap draws 179 clusters with replacement from the union of
actual RNG seeds. Each selected seed receives one shared integer multiplicity
at all budgets where it was observed. Each budget's weighted error sum is
divided by its own available-record count; unobserved budget/seed combinations
are not filled with zero. This preserves the observed dependence in the
incomplete seed panel without inventing missing experiments. Resamples with
an empty budget are discarded and redrawn (probability at most 4.4e-14 per
replicate for this saved panel). A bounded retry guard rejects excessively
sparse panels that cannot provide enough nonempty replicates.

This is an approximate percentile cluster-bootstrap confidence interval,
using 2,000 replicates and RNG seed 0, conditional on the fixed master reference
cloud of 20,000 endpoints per arm (REFERENCE_SEED + n) and the observed seed
panel. It does not measure variability from a new master reference cloud or
provide an exact finite-sample coverage guarantee. Adversarial resampling uses
30 complete base-seed records; uniform resampling uses 179 incomplete actual-
seed clusters, each budget retaining its 30 original observations for the
point estimate. All 2,000-point reference subsets retain their grouping.

Independent budget resampling is inappropriate when actual seeds overlap.
Grouping uniform rows by nominal seed_index would invent other dependencies.
Stratification by the pattern of observed budgets would freeze singleton
strata; the union-cluster bootstrap instead captures the observed cluster
covariance with per-budget normalization. The experiment's original seeds
and data remain unchanged so the saved results can still be reproduced.
